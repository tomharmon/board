## Actual differences

Additional parity verified directly against the composer, attachment rows, scheduled replies and message delivery details:

| Workflow | Native behavior and evidence |
| --- | --- |
| Pre-send labels, no-sync and send later, including queued files (`composer.tsx:55,375`, `App.tsx:387`) | [Delivery options](../ui/src/view/delivery.rs). Per-credential [stamped draft](../crates/board-core/src/drafts.rs) protects exact body, destination, privacy, labels, timing, and bytes. Posting/scheduling and consuming the draft commit together. `scheduled_private_composer_recovers_files_and_cancels_in_thread`, `stale_composer_cannot_publish_after_privacy_change_or_downgrade_an_overdue_schedule`, [genuine v7/v8 database recovery test](../crates/board-core/tests/composer_recovery.rs). |
| Optional reply guard (reference `SPEC.md:1635,2192`); repeating until a deadline (`composer.tsx:375`) | A [message detail action](../ui/src/view/properties.rs) pins that exact visible ID as the draft's newest-only condition. Polls and restarts never advance the guard; a conflict posts nothing and preserves the draft. An immediate guard cannot be scheduled. Repeating drafts accept a count or an RFC 3339 stop time, never both. `guarded_reply_pins_visible_id_across_external_write_restart_and_explicit_reselection`, `saved_newest_guard_cannot_be_removed_rebased_or_moved_outside_its_thread`, `recurring_composer_persists_stop_date_and_rejects_two_competing_stops`. |
| Copy schema definition, compose a data fence (`schemas.tsx:60-104`) | Copy any exact registered definition as pretty JSON. [Local examples](../ui/src/state/templates.rs) are derived from the selected schema, not from other messages, then checked by the core validator. Copy the complete versioned fence or append it to an existing draft. For unsolved shapes the definition remains copyable; no sample is advertised as valid. `schema_buttons_copy_exact_definition_and_valid_fenced_block_through_rune` checks actual clipboard contents using Rune's in-memory clipboard; `schema_examples_append_to_real_drafts_and_unsolved_shapes_offer_only_the_definition` submits a generated block with the shipped binary. |
| File notices, quotes, delivery state (`message.tsx:123,155,310`) | Bounds inline quotes and file notices; message details show authorized source state and attempts for the exact message, without arbitrary error payloads or receipt tokens. `exact_message_delivery_failures_are_scoped_and_local_only_replies_are_not_queued` checks an actual locally recorded copy, failure, scoped denial, literal quote, and a no-sync reply. |
| Inspect moving media (`message.tsx:166`) | [Optional decoder](../ui/src/state/video.rs) samples a user-opened local MP4/MOV with H.264: no audio, six seconds maximum at 2 fps, no paths, general URL input or external track references. `opt_in_h264_sample_steps_real_frames_and_degrades_without_the_decoder` checks the missing-decoder state; with local FFmpeg it steps/plays a four-frame fixture and measures the last frame's magenta pixels in a real Rune render. |

- This is one native, keyboard-navigable inspector, not the reference's resizable web split pane, browser history/query URLs, optimistic remote delivery or automatic long-scroll merging. It defaults to thread summaries. It polls local commits roughly once per second. Unread is a durable board-wide event checkpoint per identity, not individual channel dots stored in a browser.
- One shared filter applies to thread search and message activity, while the event log/unread checkpoint remains unfiltered. Filters are not serialized in a bookmark and do not autocomplete observed label values. The task queue's four quick lifecycle views do not expose every individual terminal state as a separate tab.
- No full-length video/audio player, animated image playback, SVG rendering, PDF viewer, external URL opening or remote avatar retrieval. Exported bytes remain usable in an application the operator chooses independently. Large resumable uploads and staged-asset reuse are not composer controls. A PNG clipboard image is supported; arbitrary clipboard HTML is not inserted as markup.
- The composer has an explicit mention picker, not an inline suggestions popover on every `@`. Scheduling accepts timezone-qualified text rather than a graphical calendar. It keeps per-thread reply drafts and one new-thread draft for the active identity, not independent new-thread drafts per channel.
- Source configuration, uncertain-delivery reconciliation, credentials issuance, access policy editing and watcher consumption/acknowledgement are **not** interactive inspector operations. Use the relevant CLI/API for supported operations. The local source review is intentionally not an external service console, and gives no proof that a real provider accepted a delivery.

Run `cargo test --locked --offline -p board-ui` after fetching dependencies. Headless operation needs a working local graphics driver (hardware or software), not a display server, provider account, HTTP service or worker. [Inspector instructions](../ui/README.md) include a reproducible PNG and element-tree command.
